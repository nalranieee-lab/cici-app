## Kendala lingkungan dan keputusan

- Percobaan pertama memperoleh pnpm dari npm registry gagal dengan ENOTFOUND
  di sandbox. Percobaan di luar sandbox melalui approval runtime berhasil.
- Menjalankan `pnpm exec tsc --noEmit` dan `pnpm build` melalui launcher
  pnpm 11 memicu pemeriksaan dependensi otomatis dan upaya instalasi yang
  gagal pada pembuatan symlink (EPERM). Ini bukan hasil compiler/build.
- Pemeriksaan diulangi menggunakan binary paket yang terpasang lokal;
  tidak memasang versi paket baru untuk mengatasi launcher.
- E-00 hanya setup/baseline di checkout yang sudah ditentukan pengguna.
  Tidak membuat branch/worktree atau mengedit source fitur di main.
- Belum ada tes otomatis dalam scripts package.json. Tidak menambahkan
  tes artifisial untuk tugas setup tanpa perubahan perilaku aplikasi.

menampilkan login. Console browser mengonfirmasi kedua konfigurasi publik

Alur login lokal belum dapat diuji; tidak
mengakses file kredensial atau menyalin sesi/token produksi.

Perbedaan awal `.figma/make/social-image.png` dipertahankan; bukan perubahan
yang dibuat E-00.

jalur konfigurasi yang diizinkan. Jangan memakai service-role/secret key.

diulang tanpa perubahan yang membenarkannya. E-00 tetap belum selesai
sampai preview menampilkan aplikasi. E-01 belum dimulai.
